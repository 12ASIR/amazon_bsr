# AM BSR 每日监控

# 3) 变更参数

# 4) 看板相关开关
python 2-脚本\01_采集与生成.py --source browser --html-days 30   # 内嵌最近 30 个快照日
python 2-脚本\01_采集与生成.py --source browser --no-html        # 只出 CSV/PNG，不生成 HTML

# 5) 离线自检（mock 服务，不消耗接口次数）

输出（明细与新增名单完全分流）：

- `3-输出\明细\{日期}\bsr_snapshot_{节点}_{日期}_{数据源}.csv` —— 当日完整榜单明细，**一天一个日期子目录**，含 `brand` / `brand_type` 列
- `3-输出\新增名单\bsr_new_entrants_{节点}_{日期}_{数据源}.csv` —— 新进入清单（有上一快照日基线时才生成），**按品牌分组 → 组内按今日名次 → 组间按各组最佳名次**排序，首列为 brand / brand_type
- `3-输出\新增名单\bsr_brand_summary_{节点}_{日期}_{数据源}.csv` —— 品牌维度汇总：new_count / best_rank / avg_price / median_price / avg_reviews / asin_list
- `3-输出\可视化\bsr_new_entrants_{节点}_{日期}_{数据源}.png` —— 三分区图：左=品牌分组名次明细（条长=101−名次，条尾标价格与评分数），右上=品牌「进入 vs 掉出」双向对比（看谁在真扩张、谁只是换链接），右下=新进入价格带直方图+均价线
- `3-输出\看板\index.html` —— **单页看板**：品牌分组视图 / 新增名单 / 当日明细 / 历史日期切换入口，见第十节
- 控制台/日志同时打印新进入 / 掉出 / 排名变动≥10

## 六、品牌解析口径（parse_brand / build_brand_map）

标题解析，不依赖外部品牌库，两遍判定：

| 类型 | 判定规则 | 归组名 |
| --- | --- | --- |
| 品牌 `brand` | 标题首个有效词不是通用词（Running / Side / Aluminum / Set / For…），且第二词若为 Auto、Star、Dynasty 等后缀则合并 | 品牌原名，如 `YZONA`、`Tyger Auto` |
| 白牌 `white` | 首词命中通用词表，且标题前 65 字符无配件关键词 | `白牌/无品牌` |
| 配件 `parts` | 首词为通用词，且前 65 字符命中 motor / end cap / step pad / replacement / bracket / hardware / mounting / clip | `配件/OEM` |
| 品牌配件 `bparts` | 品牌词开头但前段命中配件关键词（如 `ZUDKSUY … End Cap … Replacement`） | 品牌原名，图中按配件橙色展示 |
| 回捞 | 判为白牌的条目，若标题 `|` 之后出现已识别品牌名（如 `… Compatible for … | AUTOSAVER88 …`），改判为该品牌 | 品牌原名 |

已知边界：纯数字/字母混合的厂商编码（如 `68461581AA`）不作为品牌；标题内出现竞品名的极端情况可能误归，需人工抽查。

## 七、卖家精灵 API 接入要点（据官方文档）

- 网关：`https://api.sellersprite.com`
- 鉴权：请求头 `secret-key: <后台发放的访问秘钥>`，无需签名计算
- 用到的两个接口：
  - `GET /v1/product/node?marketplace=US&keyword=15736621` —— 把叶子节点解析成 `nodeIdPath`
  - `POST /v1/product/research` —— body 含 `marketplace` / `nodeIdPath` / `page` / `size`(最大100) / `order:{field:"bsr_rank"}`
- 关键口径：接口返回的 `bsr` 是**大类排名**，Running Boards 是叶子类目，故用返回项 `subcategories` 里 `code == 15736621` 的 `rank` 作为本榜名次，属于其他叶子类目的商品剔除。
- 限制：同条件只返回 TOP 2K；并发 40 次/分钟；每模块首次调用需先初始化 1 次。

## 十、网页看板（3-输出\看板\index.html）

每次运行采集流程后自动生成（除非加 `--no-html`），双击即可在浏览器打开，**不依赖网络、不起服务、纯本地文件**。

- **自包含**：唯一的外部资源是内嵌 PNG，图片以 `data:image/png;base64` 写入 HTML；不引用任何 CDN / 字体 / JS 库，断网可用
- **PNG 处理**：内嵌前按 PNG chunk 结构剥离 `tEXt / iTXt / zTXt` 文本块（保留 IHDR/PLTE/pHYs/IDAT/IEND 等），去掉 Matplotlib Software 水印字段，不影响图像内容
- **数据来源**：页面数据全部来自项目内真实 CSV（`3-输出\明细\{日期}\*_snapshot_*.csv`、`3-输出\新增名单\*_new_entrants_*.csv`、`3-输出\新增名单\*_brand_summary_*.csv`），由 Python 侧解析后序列化成 JSON 嵌入页面，前端不做任何外部请求
- **指标卡（6 项）**：榜单条数 / 品牌组数 / 新增进入 / 新增涉及品牌 / 榜单均价 / 价格区间，均由当日明细 CSV 实际字段计算
- **页面结构**：① 新增名单（按品牌分组）② 品牌维度汇总（新增口径）③ 可视化图（新增进入名单）④ 当日明细（品牌分组视图 / 逐行表可切换）⑤ 历史日期切换
- **历史切换**：顶部「历史日期」下拉 + 第 ⑤ 区日期表，均可在已内嵌的快照日之间切换，切换即整页数据联动；超出窗口的日期在 ⑤ 区给出提示
- **过滤**：顶部「过滤」框按 ASIN / 品牌 / 标题匹配，作用于 ①②④ 列表；指标卡保持全量口径，④ 区标题右侧显示过滤后 / 全量条数
- **窗口控制**：`--html-days N` 控制内嵌最近 N 个快照日（默认 14，含当日）；日期取自 `3-输出\明细\` 下实际存在的日期子目录
- **响应式**：桌面与手机宽度均可浏览，窄屏下表格横向滚动、指标卡与品牌分组纵向堆叠
